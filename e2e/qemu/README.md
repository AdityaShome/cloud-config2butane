# QEMU boot demo

Boots a real Flatcar VM from a config generated by this transpiler and
verifies it actually applied, end to end:

```
cloud-config.yaml.tmpl -> cloud-config2butane -> butane (real coreos/butane) -> ignition -> QEMU boot -> SSH assertions
```

## Prerequisites

- `qemu-system-x86_64` with KVM access (`/dev/kvm`)
- `go`, `ssh`, `ssh-keygen`, `curl`, `bzip2`
- Network access, to fetch the Flatcar QEMU image on first run (cached
  afterwards in `.cache/`, which is gitignored) and to build the `butane`
  CLI via `go install` if it isn't already on `PATH`

## Run it

```sh
./run-demo.sh
```

First run downloads and caches a Flatcar stable QEMU image (~500 MB
compressed); later runs reuse the cache. The script builds
`cloud-config2butane` fresh from this checkout, generates an ephemeral SSH
keypair, renders `cloud-config.yaml.tmpl` with that key, runs the full
convert -> validate -> compile pipeline, boots the VM headless, and SSHes in
to assert:

- the hostname was set
- the `core` user exists and is reachable with the key our tool embedded
- the generated `write_files` entry has the expected content and mode
  (`0600`)
- `runcmd` ran exactly once, on first boot
- `bootcmd` ran

The VM is killed and all generated files are cleaned up on exit,
regardless of pass/fail.

## Recording

`recording/demo.cast` is an [asciinema](https://asciinema.org) recording
of a real, passing run. Play it back with:

```sh
asciinema play recording/demo.cast
```

## Why this cloud-config isn't `testdata/golden/full-kubeadm-worker`

That fixture's `runcmd` literally runs `kubeadm join`, which can't succeed
standalone  there's no real cluster to join and no `kubeadm` binary on a
stock Flatcar image (no package manager). This demo's cloud-config mirrors
the same shape (users, a kubeadm-style file under
`/etc/kubernetes/`, runcmd, bootcmd, hostname) but swaps the runcmd/bootcmd
payloads for something that actually completes on a standalone boot, so the
demo can assert real success rather than an expected failure. The
CAPI + kind demo (`../capi-kind/`) is where an actual cluster join is
exercised.
